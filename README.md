# Screw Jack Assembly Sheet

**Author:** Naman Mandal  
**Course:** BTech Mechanical Engineering  
**Project:** Screw Jack Assembly  
**CAD Software:** AutoCAD

## Project Overview
This project documents a mechanical screw jack assembly through engineering drawings and a component parts list.

## Project Files
- CAD files: Editable drawing files
- Drawings: PDF engineering drawing
- Images: Drawing preview
- Parts List: Component names and quantities

## Learning Objectives
- Practise 2D CAD drafting
- Understand mechanical components and assembly
- Prepare dimensioned engineering drawings
- Organize and document a CAD project

## Note
This is an educational project. Verify all dimensions and specifications before manufacturing.
